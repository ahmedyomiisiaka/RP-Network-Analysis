STAGE 5 — CONTEXT-SPECIFIC RETINAL PPI FILTERING
================================================

Purpose
-------
To restrict the Stage-4 STRING protein-protein interaction network
to interactions supported in a human retinal biological context
before RP-to-apoptosis pathway reconstruction.

Input
-----
Stage-4 STRING network:
- Interactions: 9,835
- Proteins: 4,132
- RP seeds represented: 105
- STRING minimum combined score: 0.400

Evidence layers
---------------
1. Human Protein Atlas (HPA) retina tissue RNA expression
2. HPA retinal single-cell RNA expression:
   - rod photoreceptors
   - cone photoreceptors
   - retinal pigment epithelium (RPE)
   - additional retinal cell types retained as annotations
3. COMPARTMENTS subcellular localization
4. Integrated Interactions Database (IID)
5. TissueNet
6. KEGG pathway annotation
7. Reactome pathway annotation
8. ProteomicsDB investigated as supporting proteomics evidence

Evidence integration
--------------------
All evidence was integrated into a master edge-level evidence table.

Master table:
- 9,835 interactions
- 97 columns
- no duplicate STRING interaction pairs

Primary Stage-5 filtering rule
------------------------------
An interaction was retained when:

1. BOTH endpoint proteins had HPA human-retina expression evidence
   (hpa_retina_status = EXPRESSED)

AND

2. The interaction had COMPARTMENTS localization compatibility
   (compartments_status = PASS).

Retinal cell-type evidence was retained as supporting/contextual
annotation rather than used as a mandatory exclusion criterion.

Reason:
A mandatory rod/cone photoreceptor criterion would remove RP seed
genes CLN3 and TOPORS. TOPORS retained RPE expression evidence,
while both genes had HPA retina-tissue expression evidence.

IID and TissueNet were also retained as supporting interaction
evidence rather than mandatory criteria because database absence
was not interpreted as evidence that an interaction is biologically
absent.

KEGG and Reactome annotations were retained as pathway-context
evidence and were not used as mandatory interaction filters.

ProteomicsDB
------------
ProteomicsDB was investigated as an additional proteomics evidence
source. A retina biological source (BTO:0001175) was identified.
However, network-wide retina protein extraction was not obtained
under the tested API configuration. ProteomicsDB was therefore not
used as a mandatory filtering criterion.

Interpretation
--------------
The resulting network represents a retina-context-supported PPI
network rather than a retina-exclusive interactome.

Absence of evidence in IID, TissueNet, a retinal cell subtype, or
ProteomicsDB was not automatically interpreted as biological
absence.

The network is fully connected and retains all RP source proteins,
making it suitable as the input network for Stage 6 RP-to-apoptosis
pathway reconstruction.
